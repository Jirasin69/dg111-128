## 🔁 Flow การทำงาน (Flowchart)

> แก้ไข diagram ด้านล่างให้ตรงกับงานของกลุ่ม (เขียนด้วย Mermaid — ดูผลได้ใน VS Code / GitHub) หรือวาดด้วยเครื่องมืออื่นแล้วแนบรูป

```mermaid
flowchart TD
A([Start]) --> B[Play Start the game]
B --> C{what player do}
C -- Walk --> D[Walk]
C -- space --> E[Active Power]
E --> F[/the way is Block/]
D & F --> G{Do Player Collate the Item}
G -- YES --> H[Player have score]
G -- NO --> I[Player Not have score] 
I --> D
H --> J{Do Player Collate All Item}
J -- Yes --> K[/Win/]
J -- No --> L{DO Player Get Hit by Enenmy}
L -- Yes --> D
L -- Yes --> N{Do Player Get Hit 3 time}
N -- Yes --> M[/Game Over/]
N -- No --> D
K & M --> O
O([END])  
```

**State ของโปรแกรม:**

```mermaid
stateDiagram-v2
    [*] --> Start
    Start --> PLAYING : [Collate Item]
    PLAYING --> Winer : [Collate all]
    Winer --> Start
    PLAYING --> GAME_OVER : [HP=0]
    GAME_OVER --> Start 
   
```
