# 07_maze_escape — Maze Escape (2D Puzzle Game)

เกมไขปริศนาเขาวงกต 2D สไตล์เรโทร สำรวจทางเดิน เก็บไอเทมให้ครบ แล้วหนีออกทางประตูลับ ⭐⭐⭐

← กลับไป [README หลัก](../README.md)

ปรับมาจาก **Maze Escape** ของ **marsdevx** (<https://github.com/marsdevx/maze-escape>) จากเดิมที่ใช้ C + MiniLibX (สำหรับ Linux/macOS) มาเป็น **Raylib 5.x + C99** ขนาดหน้าจอ **800 × 600 px**

---

## 🔀 สิ่งที่ปรับจากต้นฉบับ
- **พอร์ตสู่ Raylib 5.x (C99):** แปลงระบบวาดกราฟิกและรับ Event จาก MiniLibX (X11 / Cocoa) มาเป็น Raylib
- **หน้าจอมาตรฐาน 800 × 600 px:** ออกแบบ Layout ใหม่ แบ่งเป็น แถบ HUD ด้านบน (70 px) + พื้นที่กระดานเขาวงกตจัดกึ่งกลางอัตโนมัติ (495 px) + แถบช่วยเหลือด้านล่าง (35 px)
- **ระบบคำนวณ Tile Size แบบยืดหยุ่น:** คำนวณขนาด Tile และ Offset อัตโนมัติเพื่อให้แผนที่ทุกขนาด (ตั้งแต่ 11×11 ถึง 29×15) อยู่ตรงกลางหน้าจออย่างสมดุล
- **แปลงรูปภาพสู่ PNG:** แปลงไฟล์ภาพ XPM ทั้ง 30 ไฟล์ (6 ธีม × 5 ภาพ) เป็น PNG เพื่อการประมวลผลบน GPU ที่รวดเร็ว
- **สลับธีมและเลือกด่านแบบ In-Game:** สามารถกด `[T]` สลับ 6 ธีมกราฟิก และกด `[1-4]` เลือกด่านได้ทันทีระหว่างเล่นโดยไม่ต้องรันผ่าน Command Line
- **การเคลื่อนที่แบบ Smooth Lerp:** ตัวละครขยับทีละช่องแบบตาราง พร้อมฟังก์ชัน Interpolation ที่นุ่มนวล และกลับด้านซ้าย-ขวาตามทิศทางการเดิน
- **ระบบ Built-in Fallback:** ฝังแผนที่สำรองไว้ในตัวโค้ด ทำให้เกมสามารถรันได้ทันทีแม้ไม่ได้วางโฟลเดอร์ `levels/`

## 🎨 6 ธีมกราฟิกในเกม (กด T เพื่อสลับ)

| ธีม | ตัวละคร (Player) | กำแพง (Wall) | ไอเทม (Item) | ทางออก (Exit) |
|-----|-------------------|--------------|--------------|---------------|
| **Pacman** | Pac-Man | กำแพงวงกตน้ำเงิน | เม็ดพลัง (Pellet) | ประตูทางออก |
| **Adventurer** | อัศวินนักผจญภัย | อิฐดันเจี้ยนหิน | อัญมณีสีแดง | ประตูมิติ (Portal) |
| **Chicken** | ไก่สีขาว | รั้วไม้ฟาร์ม | ไข่ทองคำ | โรงนา |
| **Pokemon** | ปิกาจู | พุ่มไม้หนาทึบ | โปเกบอล | ประตูห้องทดลอง |
| **Space-Ship** | ยานอวกาศ | ผนังสถานีอวกาศ | แคปซูลพลังงาน | ประตูวาร์ป |
| **Time-Adventure** | ตัวละคร Adventure Time | กำแพงแฟนตาซี | อัญมณีเวทมนตร์ | ประตูวิเศษ |

## 📜 กติกาการเล่น
1. เดินตัวละครสำรวจเส้นทางในเขาวงกต
2. เก็บไอเทมสัญลักษณ์ `'C'` ให้ครบทุกชิ้นบนกระดาน
3. ประตูทางออก `'E'` จะล็อกอยู่จนกว่าจะเก็บไอเทมครบทั้งหมด (เมื่อครบ ประตูจะมีออร่าสีเขียวเรืองแสง)
4. เดินเข้าประตูทางออกเพื่อผ่านด่านและไปยังด่านถัดไป

## 🔁 เทียบ MiniLibX → Raylib

| สิ่งที่ใช้ (MiniLibX) | Raylib ที่ใช้แทน | ประโยชน์ |
|-----------------------|------------------|----------|
| `mlx_init()` / `mlx_new_window()` | `InitWindow(800, 600, ...)` | รองรับ Cross-platform (Windows, Mac, Linux) |
| `mlx_xpm_file_to_image()` | `LoadTexture()` (PNG) | รองรับ GPU Texture เรนเดอร์รวดเร็ว |
| `mlx_put_image_to_window()` | `DrawTexturePro()` | ปรับขนาด Tile และจัดกึ่งกลางหน้าจอได้อิสระ |
| `mlx_hook()` / Event Loop | `WindowShouldClose()` + `IsKeyPressed()` | โค้ด Game Loop อ่านเข้าใจง่าย ไม่ซับซ้อน |
| Redraw ผ่านการเคลียร์จอซ้ำๆ | Double Buffering (`BeginDrawing()` / `EndDrawing()`) | จอภาพไม่กระพริบ ลื่นไหล 60 FPS |

## 🎮 ปุ่มควบคุม

| การกระทำ | ปุ่มควบคุม |
|----------|------------|
| **เดิน (Move)** | `W, A, S, D` หรือ **ปุ่มลูกศร (Arrow Keys)** |

## 🛠️ Compile & Run

```bash
# คอมไพล์ด้วย GCC MinGW บน Windows
gcc -O2 -std=c99 main.c -o maze_escape.exe -lraylib -lm -lwinmm -lgdi32

# รันเกม
./maze_escape.exe
```
