# platformer — Platformer: กระโดดเก็บเหรียญ

ควบคุมตัวละครสี่เหลี่ยมสีแดงวิ่งและกระโดดบนแท่นต่าง ๆ เพื่อเก็บเหรียญให้ครบ 10 เหรียญ (~700 บรรทัด)

เป็นเกมเดียวในชุดนี้ที่ใช้ **delta time**, **Camera2D** และฟิสิกส์แบบความเร่ง/ความหน่วง จึงเหมาะเป็นตัวอย่างอ้างอิงของ convention `x += speed * dt` ตาม CLAUDE.md ที่สุด

sample จาก raylib โดย Agnis "NeZvers" Aldiņš และ Ramon Santamaria (zlib/libpng, raylib v3.0) — ดูรายการเกมทั้งหมดที่ [README ของโฟลเดอร์ src](../README.md)

## 📜 กติกา

- แผนที่ขนาด 20 × 15 ช่อง (ช่องละ 16 px) มีกำแพงรอบด้าน + แท่นลอย 3 แท่น + บล็อกเดี่ยว 1 ก้อนที่มุมซ้ายล่าง
- เหรียญสีทอง 10 เหรียญกระจายตามแท่น — เดินชน = +1 คะแนน
- เก็บครบ 10 → ขึ้นข้อความ `PRESS [ENTER] TO PLAY AGAIN`
- **ไม่มีศัตรู ไม่มีเวลา ไม่มีแพ้** — เป็นเกมสาธิตระบบเคลื่อนที่และการชน
- คะแนนแสดงกลางบนจอ (`SCORE: n`)

## 🎮 ปุ่มควบคุม

| ปุ่ม | การกระทำ |
| --- | --- |
| `A` / `D` หรือ `←` / `→` | เดินซ้าย/ขวา (เร่งและชะลอแบบต่อเนื่อง) |
| `Space` | กระโดด — **ปล่อยเร็วจะกระโดดเตี้ย กดค้างจะกระโดดสูงสุด** |
| `Enter` | เริ่มใหม่ (หลังเก็บเหรียญครบ) |
| `Esc` | ออกจากเกม |

> โค้ดอ่านปุ่ม `W`/`S`/`↑`/`↓` เข้า `input.up`/`input.down` ด้วย แต่ยังไม่มีส่วนไหนนำไปใช้ และเกมนี้ **ไม่มีปุ่มหยุดชั่วคราว (`P`)** ต่างจากเกมอื่น

## ⚙️ ค่าคงที่และข้อมูลหลัก

| รายการ | ค่า | หมายเหตุ |
| --- | --- | --- |
| ช่องแผนที่ | `TILE_SIZE` = 16 px, 20 × 15 ช่อง | ขยายภาพ ×2.5 (`screenScale`) → หน้าต่าง 800 × 600 |
| ตัวละคร | กว้าง 8 × สูง 16 px | ตำแหน่งอ้างอิงคือ **กึ่งกลางด้านล่าง** ของตัว |
| ความเร็วสูงสุด | `maxSpd` = 1.5625 × 60 = 93.75 px/วินาที | |
| ความเร่ง / หน่วง | `acc` ≈ 425 · `dcc` ≈ 408 px/วินาที² | ออกตัวและหยุดแบบนุ่ม ไม่ใช่ทันที |
| แรงโน้มถ่วง | `gravity` ≈ 1,308 px/วินาที² | ความเร็วตกสูงสุด = ขนาดของ `jumpImpulse` |
| กระโดด | `jumpImpulse` = −393.75 px/วินาที | ปล่อยปุ่มกลางอากาศ → ลดเหลือ 20% (`jumpRelease`) |
| เหรียญ | `MAX_COINS` = 10, ขนาด 4 × 4 px | ตำแหน่งเขียนตายตัวใน array `coins[]` |

## 🧩 โครงสร้างโค้ด

- **แผนที่เป็น array 1 มิติ** `tiles[20*15]` เข้าถึงด้วย `tiles[x + y*TILE_MAP_WIDTH]` — ค่า `EMPTY` = −1, `BLOCK` = 0
- `Entity` เก็บฟิสิกส์ทั้งหมดของตัวละคร (ตำแหน่ง ความเร็ว ความเร่ง แรงโน้มถ่วง flag `isGrounded` `hitOnFloor`…) และมี pointer `control` ชี้ไปที่ `Input` ที่ใช้บังคับ — ออกแบบให้ใช้กับศัตรูหรือ AI ได้ด้วยเพียงเปลี่ยน `Input`
- **ลำดับใน `EntityMoveUpdate()`:** `GroundCheck` → `GetDirection` → `MoveCalc` → `GravityCalc` → `CollisionCheck` แล้วจึงเลื่อนตำแหน่ง
- **Sub-pixel:** เก็บเศษของพิกเซลไว้ใน `hsp`/`vsp` แล้วเลื่อนทีละจำนวนเต็ม ทำให้ตำแหน่งตัวละครติดพิกเซลเสมอ (ไม่สั่นบนแท่น)
- **ชนแยกแกน:** ตรวจแนวนอน (3 จุด: ล่าง/กลาง/บน) แล้วตรวจแนวตั้ง (3 จุด: ซ้าย/กลาง/ขวา) — ถ้าชนจะดันตัวละครไปชิดขอบช่องด้วยการ mask บิต `& ~TILE_ROUND`
- **Jump buffer:** `input.jump` เป็นสถานะที่ค้างจนกว่าจะลงพื้นหรือปล่อยปุ่ม ถ้ากดค้างขณะกำลังตก พอลงพื้นจะกระโดดต่อทันที
- เหรียญตรวจด้วย `CheckCollisionRecs` กับสี่เหลี่ยมของตัวละคร; `win = (score == MAX_COINS)`

## 🔍 ประเด็นที่น่าศึกษา

- **Delta time ของจริง:** ทุกความเร็วคูณ `delta = GetFrameTime()` — เทียบกับเกมอื่นในโฟลเดอร์นี้ที่ขยับเป็น px/frame
- **ฟิสิกส์แบบ game feel:** ความเร่ง ความหน่วง กระโดดสูงตามเวลากดปุ่ม เป็นเทคนิคมาตรฐานของ platformer
- **บิตแมสก์:** `y & ~TILE_ROUND` ใช้ได้เพราะ 16 เป็นเลขยกกำลังของ 2 (ตัวอย่างประกอบ Operators Week 4)
- **แผนที่ในโค้ด:** ตำแหน่งแท่นและเหรียญเขียนตายตัว โจทย์ต่อยอดที่ดีคือโหลดจากไฟล์
