# 05_tictactoe — Tic-Tac-Toe กระดาน N×N

เลือกขนาดกระดานและจำนวนหมากที่ต้องเรียงเพื่อชนะได้เอง ⭐⭐⭐

← กลับไป [README ของโฟลเดอร์ src](../README.md)

ปรับแนวคิดจากเกม **ttt** ของ hiimsergey (GPL-3.0, <https://github.com/hiimsergey/ttt>) — **โค้ดเขียนใหม่ทั้งหมด ไม่ได้คัดลอกจากต้นฉบับ**

## 🔀 ต่างจากต้นฉบับ
- ไฟล์ `.c` ไฟล์เดียว (ต้นฉบับแยก 5 ไฟล์ `.c/.h` ใช้ Makefile + git submodule ของ raylib)
- ใช้ **static array แทน `MemAlloc`** ตามแนวทางวิชา: ห้าม malloc ตอนเล่น (`board[MAX_N][MAX_N]`, `winCells[MAX_N*MAX_N][2]`)
- FSM แบบเดียวกับ 03: `TITLE → PLAYING → GAME_OVER`
- หน้าจอ NES-style 320×240 (4:3) ขยาย ×2.5 → 800×600

## 📜 กติกา
- เลือกขนาดกระดาน **3×3 ถึง 8×8** และ **จำนวนหมากที่ต้องเรียงต่อกัน** ที่หน้าเมนู
- ตรวจชนะด้วยการ **นับหมากต่อเนื่องใน 4 ทิศ** (แนวนอน/แนวตั้ง/ทแยงสองทิศ)
- ช่องที่ทำให้ชนะจะกะพริบ
- เก็บสถิติ X ชนะ / O ชนะ / เสมอ ข้ามรอบ
- เล่นได้ทั้งเมาส์และคีย์บอร์ด

## 📐 เลย์เอาต์
- พื้นที่กระดานสูงสุด 160 px (ก่อนขยาย) เริ่มที่ y=40 เหลือที่ด้านล่างให้ข้อความ
- ข้อความช่วยเหลืออยู่แถว 28 ข้อความสถานะจึงต้องอยู่เหนือแถว 28 เสมอ ไม่งั้นตัวหนังสือจะทับกัน

## 🔁 เทียบ dotnes → Raylib

| dotnes | Raylib |
|--------|--------|
| `pad_poll(0)` / `PAD_UP..` / `PAD_A` | `IsKeyPressed(KEY_UP..)` / `KEY_ENTER` |
| nametable (กระดาน) | `board[row][col]` |
| `ppu_wait_nmi()` | `SetTargetFPS(60)` |

## 🎮 ควบคุม

| หน้าจอ | ปุ่ม |
|--------|------|
| เลือกค่า | `↑↓` = ขนาดกระดาน · `←→` = จำนวนที่ต้องเรียง · `Enter` = เริ่ม |
| ตอนเล่น | ลูกศร / `WASD` = เลื่อน cursor · `Enter` / `Space` / `Z` หรือคลิกเมาส์ = วางหมาก · `Q` = กลับหน้าเลือกค่า |
| จบเกม | `Enter` = เล่นอีกครั้ง · `Q` = กลับเมนู |

## 🛠️ Compile
```bash
gcc -std=c99 main.c -o tictactoe -lraylib -lm -lwinmm -lgdi32
```
